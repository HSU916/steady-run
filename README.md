# 穩穩跑｜長跑配速小助手

用目標時間換算配速，並比較「穩定配速」與「前快後慢」情境對完賽時間的影響。

## 設計動機與使用者

長跑時，前幾公里跑快一點能省下多少時間？後段如果慢下來，這些時間夠不夠補回來？本作品以對長跑有興趣、想練習穩定配速的跑者為對象，將這個問題做成可操作的跑前試算工具。預設情境為半馬 2 小時。

本次重點是透過與 AI 討論規格、以 Vibe Coding 實作並驗證互動功能。網站使用確定的數學計算，沒有執行 AI 預測模型。

## 功能規格

| 項目 | 使用者操作 | 網頁回應 |
| --- | --- | --- |
| 設定目標 | 選 10 公里、半馬 21.0975 公里或全馬 42.195 公里，輸入目標小時與分鐘 | 即時換算目標平均配速 |
| 配速情境 | 按「穩定配速」或「前快後慢」；也可調整前段快慢、分段位置及後段增加百分比 | 顯示情境完賽時間、平均配速、與目標的差距，以及比較圖 |
| 分段檢查 | 查看每 5 公里與終點 | 比較穩定配速與情境的累計時間，含半馬與全馬不足 5 公里的最後一段 |
| 儲存計畫 | 輸入最多 120 字的選填筆記並按儲存 | 使用 localStorage 儲存一份設定與筆記，支援讀取與刪除 |
| 匯出表格 | 按下載配速表 CSV | 下載檢查點、兩組累計時間與差距秒數 |
| 輸入檢查 | 輸入空白、零時間或錯置分段等無效資料 | 顯示錯誤提示，暫時隱藏結果並停用儲存與下載，避免誤讀舊結果 |

## 輸入規則與預設值

- 距離：10、21.0975、42.195 公里，預設 21.0975。
- 時間：小時為 0–12 的整數，分鐘為 0–59 的整數，合計必須大於 0。預設 2 小時 0 分鐘。
- 前段差距：每公里 -30 到 +30 秒的整數；負數代表較快，預設 0。
- 分段：0 ≤ 前段終點 ≤ 後段起點 ≤ 全程公里數。半馬預設前段到 5 公里、後段從 15 公里開始。
- 後段配速秒數：以目標配速為基準增加 0–30%，預設 0%。
- 若前段配速計算後不大於 0 秒/km，視為無效。
- 切換距離會一起套用該距離的示範時間與分段：10 公里 1 小時、3/7 公里；半馬 2 小時、5/15 公里；全馬 4 小時、10/30 公里。前段差距、後段百分比及筆記保留。
- 「前快後慢」按鈕將前段差距設為 -15 秒/km、後段增加設為 15%，保留使用者的分段位置。
- 「恢復半馬 2 小時預設」重設畫面，保留已儲存資料；刪除已存計畫則不改畫面目前設定。

## 計算方式

全部以「秒」和「公里」計算，最後才轉成時間文字。

```text
目標配速 p = 目標總秒數 / 全程距離
前段配速 = p + 前段差距秒數
中段配速 = p
後段配速 = p × (1 + 增加百分比 / 100)
總時間 = 各段距離 × 各段配速的加總
時間差 = 情境總時間 - 目標總秒數
```

配速秒數增加 15% 的意思是 6:00/km 變成 6:54/km；與「速度下降 15%」的算式不同。畫面配速四捨五入至整秒，累計計算使用未取整值。分段累計時間與時間差分別取整顯示，可能有 1 秒的顯示差異。

前段跑快與後段掉速為使用者分別設定的假設，程式不假定前段加速必然導致後段掉速。

## 驗收案例

| 條件 | 預期結果 |
| --- | --- |
| 半馬 2 小時、穩定配速 | 目標約 5:41/km；完賽 2:00:00；差距 ±0:00 |
| 半馬 2 小時；前 5 公里快 15 秒/km；15 公里起配速秒數增加 15% | 前段約 5:26/km，後段約 6:32/km；完賽 2:03:57；差距 +3:57 |
| 10 公里 60 分鐘、穩定配速 | 6:00/km；終點 1:00:00 |
| 全馬 4 小時、穩定配速 | 終點包含 42.195 公里；完賽 4:00:00 |
| 目標為 0 小時 0 分鐘 | 提示時間需大於 0，隱藏結果並停用儲存及下載 |
| 前段到 16 公里、後段從 15 公里開始 | 提示分段順序錯誤 |
| 儲存情境與筆記、重新整理、按讀取 | 恢復同一組數值與筆記 |
| 手機寬度 390 px | 單欄排列，保留表格與操作按鈕；圖表刻度放大 |

本機已進行核心計算的 11 組檢查，以及瀏覽器操作、CSV 下載與桌面／手機版面檢查。這些是 AI 協助執行的測試紀錄。

## 技術與使用方式

網站程式全部在 `index.html`，包含 HTML、CSS、JavaScript，沒有套件、外部字型、API key 或後端服務。可直接開啟該檔；建議透過 GitHub Pages 使用，讓瀏覽器儲存行為更一致。

若自行部署：將 `index.html` 放在 repository 根目錄，於 Settings → Pages 選擇 Deploy from a branch、main、/(root)，儲存後等待部署完成。

## 限制

這是跑前計算工具，沒有讀取真實跑步紀錄、心率或手錶資料；不預測疲勞或提供即時警報。坡度、天氣、補給與停等未納入。儲存資料僅在目前瀏覽器與網站來源中，不會跨裝置同步；清除網站資料可能導致計畫遺失。
